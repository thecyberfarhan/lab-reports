# Lab reports

Pentest-style reports written against intentionally vulnerable training apps, run in my own isolated lab. Each report follows the same structure as a real engagement: scope, method, findings with evidence, risk ratings and fixes — not just "I found a bug."

| Target | App | Status |
|---|---|---|
| [DVWA (low security)](dvwa-low/report.md) | [Damn Vulnerable Web Application](https://github.com/digininja/DVWA) | Done |
| WebGoat | [OWASP WebGoat](https://owasp.org/www-project-webgoat/) | Planned |

These apps are deliberately insecure and meant to be attacked. All testing here was against instances I run myself, on a network only I can reach. Nothing in this repo targets a system I don't own or don't have permission to test.
